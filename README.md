# 2026 年高教社杯全国大学生数学建模竞赛 A 题

## 药材的烘干问题

本仓库收录 2026 年高教社杯全国大学生数学建模竞赛 A 题《药材的烘干问题》的参赛论文及最终支撑材料，包括四个问题的求解代码、模型检验、计算结果、论文图表和复现说明。

## 研究内容

- **问题 1：** 建立药材预热阶段的热质耦合模型，计算内部温度和水分浓度分布；
- **问题 2：** 模拟给定烘房环境下的完整烘干过程，并检验联合 Picard 迭代的收敛性；
- **问题 3：** 计算达到目标含水率所需的烘干时间，并分析物性与边界参数敏感性；
- **问题 4：** 引入药材径向收缩，建立移动边界模型，并进行退化一致性和质量平衡检验。

## 运行环境

定稿计算环境为 Python 3.12.6，主要依赖如下：

| 软件包 | 版本 |
|---|---:|
| NumPy | 2.5.1 |
| SciPy | 1.18.0 |
| OpenPyXL | 3.1.5 |
| Matplotlib | 3.11.1 |

安装依赖：

```powershell
python -m pip install numpy==2.5.1 scipy==1.18.0 openpyxl==3.1.5 matplotlib==3.11.1
```

## 快速复现

进入最终支撑材料目录后运行四个主求解器：

```powershell
cd A题支撑材料
python 问题1/问题1_求解器.py
python 问题2/问题2_求解器.py
python 问题3/问题3_求解器.py
python 问题4/问题4_求解器.py
```

部分脚本会覆盖随仓库提供的定稿工作簿或 PDF。建议先复制 `A题支撑材料/`，再在副本中执行复现。详细运行顺序、模型检验方法和结果核对值见[支撑材料复现说明](A题支撑材料/README.md)。
