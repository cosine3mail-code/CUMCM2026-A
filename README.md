## 二、建模方法

### 2.1 统一物理模型

一维径向无限长圆柱（长径比 6.25），耦合传热—传质（干燥）：

$$\rho c_p\frac{\partial T}{\partial t}=\frac{1}{r}\frac{\partial}{\partial r}\left(r k\frac{\partial T}{\partial r}\right),\qquad
\frac{\partial C}{\partial t}=\frac{1}{r}\frac{\partial}{\partial r}\left(r D\frac{\partial C}{\partial r}\right)$$

边界：表面第三类对流（$h=25$、$h_m=8\times10^{-7}$ 沿用附录 2）；中心对称。

### 2.2 关键决策

1. **物性分问选取**：问题 1 用附录 2；问题 2、3 用附录 3；问题 4 用附录 4。
2. **扩散系数** $D=D_0\,e^{-a/C}e^{-3850/T}$（C、T 都在指数**分母**上）——$e^{-a/C}$ 使 D 随干燥递减，$e^{-3850/T}$ 为 Arrhenius 型温度依赖。
3. **恒温段边界**取附件 1 平台均值 49.97 ℃ / 0.0499（附件 1 末 2 h 平均；末端 ±0.25 ℃ 噪声，末值 50.165 ℃ 是离群点，敏感性 ±0.5 h）。
4. **烘干判据**「各处 C < 0.15」等价「中心 C(r=0) < 0.15」——水分径向单调、中心最高（线性情形 Bessel 级数可证，非线性情形全剖面数值验证）。
5. **问题 4 收缩用材料（Lagrangian）坐标**：干基含水率定义在干物质上，仿射收缩下干物质质量守恒 → 水分方程退化为纯扩散（无对流项）；不能对欧拉方程做 $\xi=r/R(t)$ 变换（否则水分非物理增加）。

### 2.3 数值方法

有限体积 + 后向 Euler 隐式 + Thomas 三对角 + 耦合 Picard 迭代；材料坐标处理移动边界。

## 三、数值验证

| 验证 | 方法 | 结果 |
|---|---|---|
| 解析解 | 线性圆柱扩散 Bessel 级数对照 | 误差 ~1e-4，随网格/时间步单调下降 |
| 二维轴对称复核 | r-z 二维解 vs 一维解 | 中心偏差 −0.041 %，端面影响局部化 |

| 质量守恒 | 总含水量单调下降 | 通过 |

| 参数敏感性 | T∞/C∞/h/h_m | 时长由 T∞ 主导（−1.83 h/℃），其余稳健 |
