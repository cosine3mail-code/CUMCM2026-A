# 问题三思路：确定药材烘干所需时间

> 问题3 复用问题2 的模型（附录3 变物性、耦合传热传质），只是把求解区间从「前 3 h」延长到「整个烘干过程」，直到满足烘干判据。

---

## 1. 模型与判据

- 控制方程、物性、边界条件**与问题2 完全一致**（附录3，预热段附件1 + 恒温段 T=49.97℃/C=0.0499，平台均值）。
- **烘干判据**：药材各处水分浓度 $C<0.15$ kg/kg。因水分径向分布**中心最高**，等价于
  $$C(r=0,t)<0.15$$
  首个满足该条件的时刻即为烘干时长。

  > **「中心最高」的依据（推 + 算）**：① 物理上，水分只从表面被抽走（$C_s>C_{air}$、通量恒向外），内部无源汇，扩散只沿「高 C→低 C」传递；② **线性情形（D 常数）可严格证明**——Bessel 级数解 $C(r,t)=C_{air}+\sum_n A_n J_0(\lambda_n r/R)e^{-\lambda_n^2 Dt/R^2}$ 中 $J_0(\lambda_n r/R)$ 在 $[0,R]$ 上单调递减，故剖面单调；③ **本题非线性耦合情形经数值全剖面验证**——`单调性检查.py` 遍历全部时间步，$C[i+1]-C[i]\le0$ 的违反值恒为 0（机器精度）。

## 2. 数值设置

- 网格 $N=200$（Δr=0.01 cm）、时间步 **Δt=60 s**（与 result3 输出间隔一致），后向 Euler 隐式 + 耦合 Picard 迭代。
- 求解上限 500000 s（约 5.8 天），提前达标即停。
- 烘干时长用**线性插值**精确定位中心水分跨越 0.15 的时刻（精度优于 Δt）。

## 3. 结果

- **烘干所需时间 ≈ 57.6 h ± 0.5 h（约 2.4 天）**，落在题目「2–3 天」范围内（基准值 207443 s = 57.62 h；不确定度来自恒温段温度噪声，见 §3.1）。
- 结束时：中心 $C=0.1500$、表面 $C=0.0527$（接近平衡值 0.0499）、温度全场 ≈49.97℃（已充分热平衡）。

### 3.1 恒温段边界敏感性（噪声引入的不确定度）

附件1 只覆盖 0–4 h，末端温度有 ±0.25℃ 噪声，恒温段温度取值存在不确定。`敏感性扫描.py` 结果：

| 口径 | (T∞, C∞) | 烘干时长 / h |
|---|---|---|
| 平台均值 | (49.97, 0.0499) | 57.62 |
| 平台中位 | (49.94, 0.04989) | 57.68 |
| 末值（噪声离群点） | (50.165, 0.04986) | 57.27 |
| 平台均值（本文采用） | (49.97, 0.0499) | 57.62 |

- T∞ 是唯一主导项：噪声范围 [49.76, 50.25] → 时长 57.11~58.01 h（跨度 0.9 h，斜率 −1.83 h/℃）；
- C∞ 噪声只带来 0.02 h，可忽略；
- **结论**：烘干时长 ≈ 57.6 h ± 0.5 h；取平台均值 49.97℃/0.0499（附件1 末 2h 平均）是稳健选择，末值 50.165℃ 是噪声离群点、不宜作为恒温段常值。

## 4. 物理特征（自洽性）

表5 展示干燥由表及里、且**深干燥尾段显著变慢**：

| 时间/h | 中心 C | 表面 C | 说明 |
|---|---|---|---|
| 6 | 1.019 | 0.534 | 前期快速干燥 |
| 12 | 0.457 | 0.165 | |
| 24 | 0.238 | 0.067 | |
| 48 | 0.162 | 0.054 | 尾段显著变慢 |
| 57.6 | 0.150 | 0.053 | 达标 |

中心从 0.30（18h）降到 0.15（57.6h）用了近 40 h——这正是 $D\propto e^{-0.45/C}$ 随干燥递减（$C\to0$ 时 $D\to0$）导致的「慢尾」效应，与物理一致。

## 5. 验证清单

1. **质量守恒**：总含水量单调下降；
2. **对称性 / 全剖面单调性**：中心梯度≈0；水分 $C(r)$ 随 $r$ 严格单调递减（`单调性检查.py` 遍历全部时间步，违反值恒为 0）——即「中心最高」的数值依据；
3. **网格收敛**：烘干时长 N=100→57.71 h、N=200→57.62 h、N=400→57.59 h（收敛，Richardson 外推 ≈57.58 h）；
4. **时间步收敛**：Δt=60→57.62 h、30→57.60 h、15→57.58 h（收敛，外推 ≈57.57 h）；
5. **判据精确性**：插值定位跨零点，误差 < Δt（60 s = 1/60 h）；
6. **恒温段边界敏感性**：T∞∈[49.76, 50.25]℃ → 时长 57.11~58.01 h（±0.5 h）；C∞ 影响 <0.02 h（`敏感性扫描.py`）。

## 6. 输出

- **表5**：每 6 h（至烘干结束）× r 每 0.5 cm 的水分浓度；
- **result3.xlsx**：每 60 s × 每 0.1 cm 的水分浓度（至烘干结束，四位小数）。
