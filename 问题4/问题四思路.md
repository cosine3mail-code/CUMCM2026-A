# 问题四思路：考虑尺寸收缩的烘干时长

> 问题4 = 问题3 + 尺寸收缩（附件2 的 R(t) + 附录4 变物性）。核心难点是**移动边界的正确建模**。

---

## 1. 模型与关键决策

### 1.1 几何与坐标（最关键）

药材半径 $R(t)$ 取自附件2（2.0→1.198 cm，单调收缩）。采用**材料（Lagrangian）坐标** $\xi=r/R(t)\in[0,1]$，**仿射（均匀）收缩** $r=\xi R(t)$。

> **为什么必须用材料坐标、不能直接对欧拉方程做 $\xi=r/R(t)$ 变换**：干基含水率 $C$ 定义在干物质上，仿射收缩下每个材料单元的**干物质质量守恒**，故水分方程在 $\xi$ 坐标中**退化为纯扩散（无对流项）**；若强行对空间扩散方程做坐标变换，会多出对流项，使水分**非物理增加**（中心 C 反升到 3.66、烘干时长虚增到 99.2h vs 正解 50.8h）。

### 1.2 控制方程（材料坐标，一维轴对称）

$$\frac{\partial C}{\partial t}=\frac{1}{R^2\xi}\frac{\partial}{\partial\xi}\left(\xi D\frac{\partial C}{\partial\xi}\right),\qquad
\rho c_p\frac{\partial T}{\partial t}=\frac{1}{R^2\xi}\frac{\partial}{\partial\xi}\left(\xi k\frac{\partial T}{\partial\xi}\right)$$

附录4 物性：$\rho=760+90C$、$c_p=1850+2150\frac{C}{C+1}$、$k=0.12+0.20\frac{C}{C+1}$、$D=4.2\times10^{-4}e^{-0.30/C}e^{-3850/T}$。

### 1.3 边界与初值

- 初值 $T=28$℃、$C=2.55$；中心对称；
- 表面 $(\xi=1)$：$-\frac{k}{R}\partial_\xi T=h(T_s-T_{air})$、$-\frac{D}{R}\partial_\xi C=h_m(C_s-C_{air})$；
- 环境：预热段（0–4h 附件1）+ 恒温段（49.97℃/0.0499，平台均值，同问题3）；
- 判据：$C(r=0)<0.15$。

### 1.4 数值方法

有限体积 + 后向 Euler 隐式 + 耦合 Picard。材料坐标的离散**与问题3 物理坐标格式完全同构**，唯一区别是 $R=R(t)$ 时变（$\lambda=D\Delta t/(R^2\Delta\xi^2)$ 随收缩增大）且**不加对流项**。$N=200$、$\Delta t=60$ s。

---

## 2. 结果

- **烘干时长 ≈ 51.13 h**（184064 s，约 2.13 天），结束半径 1.200 cm；
- 结束：中心 $C=0.1500$、表面 $0.0526$、温度全场 ≈50℃；
- 表6（每 6h，固定距离 + 药材表面）：半径收缩后 1.5cm 列自动留空（材料外）。

## 3. 验证

1. **网格收敛**：N=100/200/400 → 51.146 / 51.129 / 51.124 h；
2. **时间步收敛**：Δt=60/30 → 51.129 / 51.112 h；
3. 与外部独立实现对照：参考仓库「仿射收缩」50.81 h、「外部实现」51.09 h，本文 51.13 h 落在其散布区间内，差异 0.6 % 来自恒温段边界精度（49.97 vs 50.165）+ 时间格式（一阶 vs 二阶），**非模型错误**。

## 4. 两条合规路线

| 路线 | 尺寸来源 | 烘干时长 | 说明 |
|---|---|---|---|
| A 仿射（本文） | 仅附件2 的 R(t) | **51.13 h** | 均匀收缩，假设最弱、最易复现 |
| B 非均匀（本文） | 附件2 定整体 + 附录4 ρ(C) 定局部比容 | **47.92 h** | 多一条「局部比容随 C 变」的解释 |

路线 B 采用干物质质量分数坐标 s、局部比容 $v(C)=(1+C)/\rho(C)$、映射 $r=R\sqrt{J}$，方程 $\partial C/\partial t=\frac{4I^2}{R^2}\partial_s(\frac{JD}{v^2}\partial_s C)$（见 `问题4_非均匀收缩.py`）。

**建议**：主答案取 A（仿射收缩 51.13 h），把 B 作为「改进/敏感性」给出区间 **[47.9, 51.1] h**（与参考仓库 [47.6, 50.8] h 同量级），并说明差异来自「局部收缩是否随含水率变化」这一假设。B 的网格收敛 N=100/200/400 → 47.93/47.92/47.91 h。
