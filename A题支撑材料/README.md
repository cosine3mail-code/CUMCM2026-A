## 2. 运行环境

本项目使用 Python 3.12。定稿环境版本如下：

| 软件包 | 版本 |
|---|---:|
| Python | 3.12.6 |
| NumPy | 2.5.1 |
| SciPy | 1.18.0 |
| OpenPyXL | 3.1.5 |
| Matplotlib | 3.11.1 |


使用兼容版本通常也能运行，但建议采用上表版本。中文图形显示需要系统具有“微软雅黑”或“黑体”等中文字体。

## 3. 核心结果复现

以下脚本均读取 `附件/`，并将工作簿写入对应问题的 `结果/`。为了保留随包提供的定稿文件，建议先复制整个支撑材料目录，再在副本中运行。

```powershell
python 问题1/问题1_求解器.py
python 问题2/问题2_求解器.py
python 问题3/问题3_求解器.py
python 问题4/问题4_求解器.py
```

应得到以下关键输出：

| 问题 | 核对值 |
|---|---|
| 问题1 | 1800 s温度：33.5761→36.7860 ℃；水分：2.5500→1.5103 kg/kg |
| 问题2 | 3 h温度：49.8493→49.9666 ℃；水分：1.7662→1.0081 kg/kg |
| 问题3 | 烘干时长：207443.3 s = 57.6231 h |
| 问题4 | 仿射收缩烘干时长：184229.8 s = 51.1749 h |

问题1主求解器采用 $N=800$、$\Delta t=0.25$ s、$\Delta r=2.5\times10^{-5}$ m；问题2采用 $N=200$、$\Delta t=1$ s；问题3、4采用 $N=200$、$\Delta t=60$ s。烘干判据为中心水分浓度首次低于0.15，跨越时刻采用线性插值。

## 4. 检验代码复现

```powershell
# 问题1：Bessel解析解检验（结果输出到终端）
python 问题1/问题1_Bessel解析检验.py

# 问题1：有限圆柱二维轴对称复核（重绘图7）
python 问题1/问题1_一维径向复核.py

# 问题2：联合Picard迭代收敛曲线（重绘图9）
python 问题2/问题2_Picard收敛检验.py

# 问题3：物性与边界参数±5%单因素敏感性
python 问题3/问题3_参数敏感性.py

# 问题4：固定半径退化一致性与水分质量平衡（重绘图12）
python 问题4/问题4_收缩退化检验.py
```

主要检验基准：

- Bessel解析解：$N=400$、$\Delta t=1$ s时最大误差为 $8.970\times10^{-5}$ kg/kg；
- 二维轴对称复核：含水率、温度端面影响长度分别为0.75 cm、3.20 cm，中面差异可忽略；
- 问题2 Picard迭代：温度和水分收敛阈值分别为 $10^{-6}$、$10^{-8}$；
- 问题4退化检验：最大温度差 $3.083755\times10^{-12}$ ℃，最大水分差 $2.142730\times10^{-14}$ kg/kg；
- 问题4最大相对质量平衡残差：$2.351061\times10^{-15}$。

## 5. 论文图复现

依赖已有结果工作簿的热力图可按下列顺序重绘：

```powershell
python 问题1/问题1_热力图.py
python 问题3/问题3_热力图.py
python 问题4/问题4_热力图.py
```

`问题1_图2图5绘图.py` 使用自身的插值对照网格，并会写入 `问题1/结果/`。如需重绘图2和图5，请务必在支撑材料副本中运行，避免覆盖主求解器的N=800定稿结果：

```powershell
python 问题1/问题1_图2图5绘图.py
```

图8、图10和图11由对应热力图脚本读取结果工作簿生成；图9、图12由对应检验脚本生成。PDF重新生成后可能因字体或文件元数据产生字节差异，核对时应以图中曲线和数值为准。
